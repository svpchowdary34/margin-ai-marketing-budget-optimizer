# MARGIN AI
Turn marketing spend into measurable profit.

Marketing budget intelligence: campaign ROAS/ROI/CAC, profitability, constrained budget optimisation and scenarios.

## Run
`pip install -r requirements.txt && python app.py` (or paste into one Colab cell).

## Notes
- Bundled sample data is **fictional**.
- Attributed results are not incremental/causal.
- Optional LLM key: set `ANTHROPIC_API_KEY` as an environment variable or Colab secret. Never commit keys.
